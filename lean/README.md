# AR18RaceManMachine

Own partial formalization of NBER Working Paper 22252, June 2017. Three conditional static-response algebra contracts compile; the required fast check passes with exit code 0. See [validation results](audit/check_results.json), [proof code](MainTheorems.lean), [transparent Specs](PaperInterface.lean), and [scope](docs/CHECKPOINT.md).

All original paper propositions remain open. A successful algebra build does not establish the continuum equilibrium, its derivatives, the dynamic BGP results, or source-to-Lean equivalence. There is no accepted semantic audit or closure receipt.
